## 语言

### 工单调查

**工单调查助手**:
帮助部门主管以指定工单为起点、按需参考本部门其他工单记录，核对处理进展并形成后续建议的辅助能力。这里的本部门工单指提交人当前与该主管属于同一部门的工单，升级工单也不扩大范围。调查结果供人判断，不直接改变工单的处理结果。
_Avoid_: 自动处理人、自动分诊、自动派单

**调查结论**:
对工单调查中可确认的事实、尚缺少的证据以及下一步核实建议的汇总。调查结论可以明确原因尚未查明，不以给出延误原因作为成立条件。
_Avoid_: 根因判决、自动定责

**一次调查**:
由主管针对明确工单与问题发起的一次独立调查过程，不自动沿用上一次调查的对话上下文。一次调查可以查阅多份记录，形成一份本次调查结论。
_Avoid_: 连续聊天、长期会话
